# TO-BE Process

## 1. Process Name

Proposed Employee Leave Management Process

## 2. Process Objective

The objective of the proposed process is to replace the manual email and spreadsheet-based workflow with a centralized digital leave management process.

## 3. Proposed Process Flow

Employee
   ↓
Login to System
   ↓
Submit Leave Request
   ↓
System Validates Request
   ↓
Request Status = Pending
   ↓
Manager Reviews Request
   ↓
Approve / Reject
   ↓
System Updates Request Status
   ↓
Employee Views Updated Status
   ↓
HR Records and Reports Updated

## 4. Proposed Process Steps

| Step | Actor | Activity |
|---|---|---|
| 1 | Employee | Logs into the system |
| 2 | Employee | Enters leave details |
| 3 | System | Validates the request |
| 4 | System | Creates the request with Pending status |
| 5 | Manager | Reviews the request |
| 6 | Manager | Approves or rejects the request |
| 7 | System | Updates the request status |
| 8 | Employee | Views the updated status |
| 9 | HR | Views centralized leave records and reports |

## 5. Expected Improvements

- Reduced manual data entry.
- Centralized leave information.
- Improved request tracking.
- Faster communication of approval decisions.
- Better visibility for employees and managers.
- Easier access to HR records.
- Improved reporting capabilities.
