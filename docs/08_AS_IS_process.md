# AS-IS Process Analysis

## 1. Process Name

Current Employee Leave Request and Approval Process

## 2. Process Description

The current employee leave process is primarily managed through email communication and manually maintained spreadsheets.

## 3. Current Process Flow

Employee
   ↓
Submit Leave Request Through Email
   ↓
Manager Receives Request
   ↓
Manager Reviews Request
   ↓
Manager Approves / Rejects
   ↓
HR Receives Leave Information
   ↓
HR Manually Updates Spreadsheet
   ↓
Employee Receives Status Through Email

## 4. Process Steps

| Step | Actor | Activity |
|---|---|---|
| 1 | Employee | Sends leave request through email |
| 2 | Manager | Reviews the leave request |
| 3 | Manager | Approves or rejects the request |
| 4 | HR | Receives the decision |
| 5 | HR | Updates leave records manually |
| 6 | Employee | Receives the decision through email |

## 5. Problems in Current Process

### Manual Data Entry

HR needs to manually update spreadsheets after receiving leave information.

### Communication Dependency

The process depends heavily on email communication between employees, managers, and HR.

### Limited Visibility

Employees do not have a centralized dashboard to track requests.

### Reporting Effort

HR may need to manually organize spreadsheet information to prepare reports.

### Risk of Errors

Manual data entry can result in incorrect or inconsistent records.

### Lack of Centralized Tracking

There is no single system where employees, managers, and HR can view relevant leave information.

## 6. Process Improvement Opportunity

The current process can be improved by introducing a centralized system where leave requests, approvals, statuses, and records are managed within one workflow.
